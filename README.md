# Minha Loja — Force Games Tecnologia

Distribuição oficial do programa Windows de vendas, serviços, estoque e fiado.
Este repositório contém somente os arquivos compilados, documentação de uso e o manifesto assinado de atualização. O código-fonte é mantido em repositório privado. O uso exige uma autorização válida.

## Baixar
Abra [a versão mais recente](https://github.com/xCoronelMakerx/minha-loja-atualizacoes/releases/latest).
- Primeira instalação: baixe o arquivo Setup.exe.
- Já usa uma versão antiga: baixe o ZIP de atualização, extraia tudo, feche o programa e execute Atualizar.cmd.
- A partir da versão 0.2.1: use Configurações > Atualizações > Verificar atualizações. Ao confirmar uma versão nova, o programa cria uma cópia dos dados e inicia o atualizador.

Atualizações preservam dados e a autorização, sem reiniciar o prazo da avaliação. Dados de clientes, autorizações individuais e chaves privadas não são publicados aqui.
